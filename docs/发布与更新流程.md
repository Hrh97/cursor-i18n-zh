# 发布与更新流程（维护者）

给以后发版用的固定流程。Agent / 维护者按此执行即可。

## 仓库

| 项 | 值 |
|----|-----|
| 主目录 | `~/Projects/cursor-i18n-zh` |
| GitHub | https://github.com/baishi1114010/cursor-i18n-zh |
| 分支 | `main` |
| 备用副本 | `~/cursor-i18n-zh`（发版后同步） |

## 用户触发话术

- 「根据截图补汉化 / 更新汉化包」→ 补词条 + 升版本 + 本地应用
- 「发布 / 推到 GitHub」→ commit + push
- 「Windows 安装说明」→ 维护 `docs/Windows安装使用指南.md`

## 发版检查清单

- [ ] 从 Cursor 安装包或 `~/.cursor-i18n-zh/backups/<版本>/` 核对英文原文（大小写、模板）
- [ ] 更新 `src/dict-settings-pages.js` / `settings-nav.js` / `tricky.js` / `audit.js`
- [ ] 跳过：用户 Rules/Skills 正文、模型品牌名、动态价格
- [ ] `package.json` + `index.js` VERSION 同步递增
- [ ] 新增 `docs/UPDATE-vX.Y.Z.md`，更新 `README.md` 更新日志
- [ ] 对英文 backup 抽检翻译命中
- [ ] Cursor 完全退出后执行 `node index.js localize`
- [ ] 用户确认后：`git commit` + `git push origin main`
- [ ] 同步关键文件到 `~/cursor-i18n-zh`

## 版本号约定

- **补丁** `1.2.x`：少量词条 / 文案修正
- **次版本** `1.x.0`：新 Settings 页或截图大批补全（如 1.2.0）
- **主版本** `x.0.0`：架构或替换策略大改

## Windows 用户文档

完整小白指南：[`Windows安装使用指南.md`](./Windows安装使用指南.md)

关键命令：

```text
node index.js localize
node index.js localize -p "D:\software\cursor"

```
